Aviso de privacidade

Texto curto sobre o que acontece com os dados que você vê ou digita neste site. Não é um contrato e não substitui a política que uma empresa formalizada deve publicar quando houver CNPJ e tratamento contínuo de dados.

O gerador fica no seu aparelho

A página Montar uma defesa monta a carta, o checklist e os passos só no seu navegador. Os dados do caso (cliente, pedido, endereço, rastreio, conversas, identificadores da transação) não são enviados a um servidor nosso: não há backend, conta nem banco de dados neste site. Também não gravamos esses dados em cookie, localStorage ou arquivo remoto. Se você fechar a aba, o que estava no formulário some com ela, salvo o que o próprio navegador tiver oferecido salvar no preenchimento automático.

Não pedimos número completo de cartão, validade nem CVV. Não cole esses dados em nenhum campo.

O que este site ainda comunica pela rede

Abrir qualquer página faz o navegador baixar os arquivos estáticos no GitHub Pages (GitHub / Microsoft). Isso é o acesso normal a um site: endereço da página, seu IP e dados técnicos da conexão. O conteúdo que você digita no gerador não vai nessa requisição.

As fontes tipográficas vêm do Google Fonts. O Google pode ver que você abriu este site (por exemplo, seu IP). Isso não inclui o texto do formulário.

Não usamos ferramentas de medição, pixel ou anúncio.

Se você nos escrever no WhatsApp

Aí a conversa passa pelo WhatsApp (Meta) e chega ao nosso número. Usamos só o necessário para montar aquela defesa e não pedimos dado de cartão completo. Para falar sobre o que foi enviado ou pedir que apaguemos a conversa, use o mesmo WhatsApp.
