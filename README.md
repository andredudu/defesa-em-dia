# Defesa em Dia

Site estático com a página de apresentação e um gerador de **carta de defesa**, **checklist de provas** e **passos no portal** para chargeback no Brasil (Cielo, Stone, Mercado Pago, PagBank, Getnet, Pagar.me e Rede).

Isto **não é aconselhamento jurídico** e **não garante** que o banco aceite a disputa. O prazo que vale é o da notificação do adquirente, mesmo quando uma página oficial disser outra coisa. Não envie número completo de cartão, validade nem CVV.

O formulário roda inteiro no navegador: os dados do caso **não são enviados a um servidor**.

## Rodar localmente

```bash
python3 -m http.server 8080
```

Abra http://127.0.0.1:8080/ e http://127.0.0.1:8080/app.html.
